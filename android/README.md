# Календарь — Android-приложение

Нативное Android-приложение на Kotlin + Jetpack Compose + Room. Повторяет функциональность
веб-версии календаря (см. корень репозитория), но хранит данные локально в SQLite через Room.

## Возможности

- Месячный вид с навигацией по месяцам и кнопкой «Сегодня»
- Выбор дня → список событий этого дня внизу экрана
- Добавление/редактирование/удаление события через нижний лист (bottom sheet):
  название, дата, время начала/конца или отметка «весь день», цвет, заметка
- Поиск по названию и заметкам
- Данные сохраняются локально в базе Room (переживают перезапуск приложения)
- Material 3, поддержка динамических цветов (Android 12+) и тёмной темы

## Структура проекта

```
android/
  app/src/main/java/com/koshg/calendar/
    MainActivity.kt          — точка входа, создаёт ViewModel и Compose-дерево
    data/                    — Room: Entity, Dao, Database, Repository
    ui/                      — ViewModel, экран календаря, форма события
    ui/theme/                — Material 3 тема
    util/DateUtils.kt        — форматирование дат на русском
```

## Сборка

Проект собирается стандартным способом через Gradle (обёртка `gradlew` уже включена):

1. Откройте папку `android/` в Android Studio (Koala/Ladybug или новее) — она сама
   предложит установить недостающие компоненты Android SDK (compileSdk 34, build-tools).
2. Или из терминала, если Android SDK уже установлен и `ANDROID_HOME`/`local.properties`
   настроены:
   ```bash
   ./gradlew assembleDebug
   ```
   APK появится в `app/build/outputs/apk/debug/`.

**Важно:** в текущей среде разработки (песочнице агента) нет доступа к Android SDK и к
`dl.google.com`, откуда Gradle обычно скачивает Android SDK и библиотеки AndroidX/Compose —
поэтому здесь проект собрать и прогнать нельзя. Код написан вручную и вычитан, но
полноценно скомпилировать и протестировать на устройстве/эмуляторе стоит в Android Studio.

## Минимальные требования

- minSdk 26 (Android 8.0+)
- compileSdk / targetSdk 34
- Kotlin 2.0, AGP 8.5.2, JDK 17
