# Календарь — Android-приложение

Нативное Android-приложение на Kotlin + Jetpack Compose + Room. Помимо обычного календаря
включает трекер женского цикла с прогнозом по фазам и приватный журнал близости для пары. Все
данные хранятся только локально на устройстве (SQLite через Room) — ничего никуда не
отправляется и не синхронизируется.

## Возможности

Всё живёт на **одном экране** — календаре, без отдельных вкладок.

**Календарь**
- Месячный вид, всегда 6 недель (чтобы сетка не «прыгала» при свайпе между месяцами), свайп и
  стрелки для навигации, кнопка «Сегодня»
- Каждый день окрашен по фазе цикла — менструация, фолликулярная, пик ЛГ, овуляция, лютеиновая —
  цвет плавно перетекает от одной фазы к другой, без резких переходов на стыке
- Долгое нажатие на дату открывает форму добавления записи сразу на этот день
- Кнопка «+» открывает единую форму (Месячные / Секс / Предложение / Мастурбация) — плавающим
  окном по центру экрана, с системным блюром фона
- Компактная строка статистики цикла над сеткой; единая панель дня под ней — события, запись
  месячных, близость вместе, каждая запись редактируется и удаляется по тапу
- Экран «История и тренды»: длина цикла (среднее/мин/макс), частота записей по месяцам, процент
  принятых предложений

**Маркеры в сетке**
- Цветное кольцо вокруг числа — была близость, предложение принято/отклонено или отмечена
  мастурбация (в этом порядке приоритета)
- Золотая звёздочка — в этот день был оргазм
- Точки под числом — обычные события календаря (до 3, дальше не показываются)

**Настройки** (отдельный экран, открывается из шапки)
- Блокировка приложения биометрией или PIN/паролем устройства
- Длина лютеиновой фазы — переопределяется, если известна своя норма
- Оформление: заливка или пунктир для отображения фаз, яркие или приглушённые цвета фаз,
  адаптивная тема (акцент подстраивается под текущую фазу цикла), градиентная заливка внутри
  одной фазы
- О приложении: версия, пояснение про локальное хранение данных

**Цикл**
- Вручную вносится только дата начала месячных
- Овуляция, пик ЛГ, фертильное окно и прогноз следующих месячных считаются автоматически по
  EWMA-модели (экспоненциально взвешенное среднее длины цикла), с динамической шириной окна
  погрешности и флагом «нерегулярный цикл» при большом разбросе длин

**Близость**
- «Секс»: дата, инициатор, количество оргазмов, заметка
- «Предложение»: дата, инициатор, принято/отклонено, причина отказа (если отклонено), заметка
- «Мастурбация»: дата, кто, количество оргазмов, заметка

**Общее**
- Тактильная отдача на ключевых действиях — выбор дня, сохранение, удаление, свайп между
  месяцами — свои паттерны вибрации под каждое действие
- Родная заставка (splash screen) с анимацией при запуске
- Material 3, тёмная тема
- Современная адаптивная иконка (розово-фиолетовый градиент, календарь+сердце)

## Структура проекта

```
android/
  app/src/main/java/com/koshg/calendar/
    MainActivity.kt          — точка входа: заставка, блокировка приложения, репозитории/ViewModel
    data/                    — Room: Entity/Dao/Database/Repository
                                (события, месячные, секс, предложения, мастурбация)
    haptics/                 — обёртка над VibratorManager + CompositionLocal
    security/                — биометрическая блокировка приложения (BiometricPrompt)
    settings/                — настройки цикла и оформления (SharedPreferences)
    ui/CalendarScreen.kt     — единый экран: шапка, сетка, оркестрация форм
    ui/SettingsScreen.kt     — экран настроек
    ui/HistoryScreen.kt      — история и тренды
    ui/DayAgendaPanel.kt     — карточка статистики цикла + панель дня
    ui/IntimacySheets.kt     — формы добавления/редактирования всех записей
    ui/theme/                — Material 3 тема, цвета фаз, приглушение/градиенты
    util/
      DateUtils.kt           — форматирование дат на русском (с учётом падежей)
      CycleCalculator.kt     — EWMA-прогноз, фазы цикла, фертильное окно
```

## Сборка

Проект собирается стандартным способом через Gradle (обёртка `gradlew` уже включена):

1. Откройте папку `android/` в Android Studio (последняя стабильная версия) — она сама
   предложит установить недостающие компоненты Android SDK (compileSdk 36, build-tools).
2. Или из терминала, если Android SDK уже установлен и `ANDROID_HOME`/`local.properties`
   настроены:
   ```bash
   ./gradlew assembleDebug
   ```
   APK появится в `app/build/outputs/apk/debug/`.

Актуальность кода на каждый пуш в ветку проверяется в GitHub Actions
(`.github/workflows/android-ci.yml`, сборка `assembleDebug`), а релизный APK собирается и
публикуется в GitHub Releases (`.github/workflows/android-release.yml`).

**Важно:** в песочнице агента, где писался этот код, нет доступа к Android SDK и к
`dl.google.com` — собрать и прогнать проект локально там нельзя. Поэтому вся сборка и
проверка компиляции идёт через GitHub Actions.

## Минимальные требования

- **minSdk 36 (Android 16) — только актуальные устройства**, без веток обратной
  совместимости для более старых версий Android
- compileSdk / targetSdk 36
- Kotlin 2.0.21, AGP 8.7.3, JDK 17

## Приватность

Все данные (события, месячные, записи близости) хранятся только в локальной базе Room на
устройстве. Приложение не запрашивает доступ к сети, не содержит аналитики и ничего никуда
не отправляет.
