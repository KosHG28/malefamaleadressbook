# Календарь — Android-приложение

Нативное Android-приложение на Kotlin + Jetpack Compose + Room. Помимо обычного календаря
включает трекер женского цикла и приватный журнал близости для пары. Все данные хранятся
только локально на устройстве (SQLite через Room) — ничего никуда не отправляется и не
синхронизируется.

## Возможности

**Календарь**
- Месячный вид с навигацией по месяцам и кнопкой «Сегодня»
- Добавление/редактирование/удаление события через нижний лист: название, дата,
  время начала/конца или отметка «весь день», цвет, заметка
- Поиск по названию и заметкам
- На днях в сетке видны маркеры цикла и близости (см. ниже)

**Цикл** (вкладка «Цикл»)
- Вручную вносятся только даты начала месячных
- Овуляция, фертильное окно и прогноз следующих месячных считаются автоматически
  (средняя длина цикла — по истории, по умолчанию 28 дней, лютеиновая фаза 14 дней)
- В календаре: дни месячных подсвечены розовым, фертильное окно — зелёным,
  день овуляции отмечен кружком

**Близость** (вкладка «Близость»)
- Отдельные журналы: «Секс» (дата + кто был инициатором) и «Предложения»
  (дата + инициатор + принято/отклонено), у каждой записи есть заметка
- В календаре дни с записью помечены сердечком (закрашенное — был секс,
  контурное — только предложение)

**Общее**
- Тактильная отдача (haptics) на ключевых действиях — выбор дня, сохранение,
  удаление, переключение вкладок, свои паттерны вибрации под каждое действие
- Material 3 с динамическими цветами из обоев устройства, тёмная тема
- Современная адаптивная иконка (розово-фиолетовый градиент, календарь+сердце)

## Структура проекта

```
android/
  app/src/main/java/com/koshg/calendar/
    MainActivity.kt          — точка входа, собирает репозитории/ViewModel
    data/                    — Room: Entity/Dao/Database/Repository
                                (события, месячные, секс, предложения)
    haptics/                 — обёртка над VibratorManager + CompositionLocal
    ui/                      — ViewModel-ы и экраны (Calendar/Cycle/Intimacy),
                                AppRoot — нижняя навигация
    ui/theme/                — Material 3 тема, акцентные цвета (period/fertile/…)
    util/
      DateUtils.kt           — форматирование дат на русском
      CycleCalculator.kt     — расчёт овуляции/фертильного окна/прогнозов
```

## Сборка

Проект собирается стандартным способом через Gradle (обёртка `gradlew` уже включена):

1. Откройте папку `android/` в Android Studio (последняя стабильная версия) — она сама
   предложит установить недостающие компоненты Android SDK (compileSdk 36, build-tools).
2. Или из терминала, если Android SDK уже установлен и `ANDROID_HOME`/`local.properties`
   настроены:
   ```bash
   ./gradlew assembleDebug
   ```
   APK появится в `app/build/outputs/apk/debug/`.

Актуальность кода на каждый пуш в ветку проверяется в GitHub Actions
(`.github/workflows/android-ci.yml`, сборка `assembleDebug`), а релизный APK собирается и
публикуется в GitHub Releases (`.github/workflows/android-release.yml`).

**Важно:** в песочнице агента, где писался этот код, нет доступа к Android SDK и к
`dl.google.com` — собрать и прогнать проект локально там нельзя. Поэтому вся сборка и
проверка компиляции идёт через GitHub Actions.

## Минимальные требования

- **minSdk 36 (Android 16) — только актуальные устройства**, без веток обратной
  совместимости для более старых версий Android
- compileSdk / targetSdk 36
- Kotlin 2.0.21, AGP 8.7.3, JDK 17

## Приватность

Все данные (события, месячные, записи близости) хранятся только в локальной базе Room на
устройстве. Приложение не запрашивает доступ к сети, не содержит аналитики и ничего никуда
не отправляет.
