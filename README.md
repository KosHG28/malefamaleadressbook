# Календарь

Два приложения календаря:

- **Android-версия** — [`android/`](android/) — нативное приложение на Kotlin + Jetpack Compose +
  Room: месячный календарь, трекер женского цикла с прогнозом по фазам и приватный журнал
  близости для пары. Все данные хранятся только на устройстве.
- **Веб-версия** (этот каталог) — чистые HTML/CSS/JS, без сборки и зависимостей: простой
  календарь событий.

## Веб-версия

Простое веб-приложение календаря на чистых HTML/CSS/JS, без сборки и зависимостей.

## Возможности

- Месячный вид с навигацией по месяцам и кнопкой «Сегодня»
- Добавление, редактирование и удаление событий (клик по дню, двойной клик для быстрого создания)
- Событие с названием, датой, временем (или отметкой «весь день»), цветом и заметкой
- Список событий выбранного дня в боковой панели
- Поиск по названию и заметкам событий
- Данные сохраняются в `localStorage` браузера

## Запуск

Откройте `index.html` в браузере, либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
```

и перейдите на `http://localhost:8000`.
