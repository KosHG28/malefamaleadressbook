# Ответы на анкеты Play Console

Три анкеты, которые Play заставляет заполнить перед публикацией. Здесь готовые ответы —
сверенные с тем, что приложение реально делает, а не с тем, как хотелось бы.

---

## 1. Безопасность данных (Data safety)

**Собирает ли приложение данные пользователя или передаёт их?** → **Нет**

Это не маркетинговая формулировка, а факт, который легко проверить: в
`AndroidManifest.xml` объявлены ровно два разрешения — `VIBRATE` и `POST_NOTIFICATIONS`.
Разрешения `INTERNET` нет. Приложение технически не может открыть сетевое соединение,
так что ни собирать, ни передавать данные ему нечем.

Дальше анкета сама схлопнется и спросит только:

| Вопрос | Ответ |
| --- | --- |
| Шифруются ли данные при передаче | *(вопрос не появится — передачи нет)* |
| Может ли пользователь запросить удаление данных | **Да** — удаление любой записи внутри приложения, полное удаление вместе с приложением |
| Прошли ли вы независимую проверку безопасности | **Нет** |

### Одна честная оговорка про Auto Backup

Приложение оставляет включённым системный Android Auto Backup: если пользователь не
отключил резервное копирование в настройках телефона, сама операционная система может
скопировать базу приложения в его собственный Google-аккаунт.

Формально это **не** сбор данных приложением: копирование делает Android, данные уходят
в аккаунт самого пользователя, разработчик доступа к ним не имеет, и включает/отключает
это пользователь в общесистемных настройках, а не в приложении. Google собственные
руководства по анкете к платформенным механизмам резервного копирования не относит,
поэтому ответ «Нет» корректен.

Тем не менее это единственное место, где данные покидают телефон, поэтому оно подробно
описано в политике конфиденциальности отдельным разделом. Если модерация всё же
переспросит — ссылайтесь на этот раздел политики, там всё уже написано.

## 2. Возрастной рейтинг (анкета IARC)

Отвечать нужно честно: приложение ведёт дневник половой жизни. Оно **не показывает**
никакого эротического содержимого — ни изображений, ни описаний, только даты, отметки
и числа.

| Вопрос анкеты | Ответ |
| --- | --- |
| Насилие | Нет |
| Пугающий контент | Нет |
| Сексуальный контент и нагота | **Да, упоминания** — приложение позволяет вести учёт половой жизни; изображений и откровенных описаний нет |
| Ненормативная лексика | Нет |
| Наркотики, алкоголь, табак | Нет |
| Азартные игры | Нет |
| Пользовательский контент / общение между пользователями | **Нет** — заметки видны только владельцу телефона, обмена между пользователями нет |
| Передача местоположения | Нет |
| Передача персональных данных | Нет |
| Покупки в приложении | Нет |

Ожидаемый результат: **18+** в российской системе, **Mature 17+** в ESRB. Это нормально
для трекера цикла с разделом близости, и это же значение стоит выбрать в поле «Целевая
аудитория».

Не пытайтесь занизить рейтинг, убрав упоминание половой жизни: если модерация увидит
расхождение между анкетой и содержимым, приложение снимают с публикации, и вернуть его
сложнее, чем получить рейтинг 18+ сразу.

### Про «приложение для здоровья»

Play отдельно спрашивает про приложения, работающие со здоровьем. Interlude отвечает
«Нет»: оно не подключается к Health Connect, не читает медицинские данные из других
приложений и не выдаёт себя за медицинское изделие. Отказ от ответственности на этот
счёт есть и в описании карточки, и внутри приложения.
